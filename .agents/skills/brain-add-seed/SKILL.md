# brain-add-seed — 내 생각 씨앗 심기 (`Ark/`)

> 파이프라인 위치: **`Welcome/` 또는 대화 속 아이디어를 `Ark/` 내 주제 방에 첫 씨앗(`stage: seed`)으로 심는 단계**입니다.

## ⚙️ 경로 설정 (`Kobot-AI-OS-Starter`)

| 이름 | 설정값 | 설명 |
|---|---|---|
| `TOPICS_DIR` | `Ark/` | 온보딩 시 생성한 내 주제 방들 (`Blocks/` 제외) |
| `REGS_FILE` | `0_Me/_FRONTMATTER_REGS.md` | 허용된 소문자 `tags` 목록 확인 기준 |
| `TEMPLATE` | `_TEMPLATES_/BRAIN-Note.md` | `요약 → 1. 개요 → 2. 생각 → 3. 활용` 뼈대 |

---

## 언제 사용하나요
- 공부·AI 대화 중 이해한 개념을 휘발시키지 않고 내 말로 고정하고 싶을 때
- `Welcome/`에 던져 둔 짧은 메모나 인사이트를 정제하고 싶을 때
- 강의·데이터시트를 보다가 떠오른 개인 의견이나 질문을 남기고 싶을 때

---

## 에이전트 실행 절차

### 1. 입력 확인 & 저장할 방(주제) 결정
- `/brain-add-seed` + 파일 경로(`Welcome/...` 등) 또는 직접 입력한 생각/텍스트를 받습니다.
- `Ark/` 아래 실제 존재하는 주제 방(`Blocks/` 제외)과 `0_Me/_FRONTMATTER_REGS.md`의 `tags` 목록을 먼저 확인합니다.
- 내용상 분명하면 방과 태그를 추론해 제안하고, 애매하면 질문합니다. AI가 임의로 새 하위 폴더를 만들지 않습니다.

### 2. B·R·A 3가지 핵심 질문 (필수 — 답 없이 임의 작성 금지)
차례대로 또는 간결히 묻되, 사용자 답변이 부족하면 한 번 더 짚어 묻습니다.

| # | 섹션 | 질문 |
|---|---|---|
| **B** | 개요 (`Background`) | "이 생각이 어디서 나왔는지, 어떤 공부·상황에서 만났는지 알려주시겠어요?" |
| **R** | 공명 (`Resonate`) | "핵심적으로 와닿은 한 줄(또는 가장 중요하다고 느낀 포인트)은 무엇인가요?" |
| **A** | 확장 (`Amplify`) | "① 다음에 다시 봐도 안 헷갈리거나 팀원에게 보여줄 때 어떤 형태(비유·도식·시뮬레이션·실습)로 남기면 좋을지, 또는 ② 아직 남은 의문·반론이 무엇인가요?" |

> **원칙:** `seed` 단계에서는 **`요약` · `1. 개요` · `2. 생각(R/A)`**까지만 채웁니다. **`3. 활용(I/N)`**은 `/brain-connect` 단계에서 채우며 지금은 빈 틀을 유지합니다.

### 3. 파일명 및 Frontmatter 규약 (`0_Me/_FRONTMATTER_REGS.md` 준수)
- **저장 경로:** `Ark/<선택한 방>/<한 문장 명제>.md`
- **파일명:** R(공명)에서 도출한 **한 문장 명제** (예: `PWM 듀티비가 모터의 평균 인가 전압을 결정한다.md`). 기존 동일 파일명이 있으면 덮어쓰지 않고 먼저 확인합니다.

```yaml
---
type: note
created: YYYY-MM-DD
tags:
  - embedded # 0_Me/_FRONTMATTER_REGS.md에 등록된 내 주제 태그 중 선택
status: draft     # 5규약 유지 (seed 단계는 항상 draft)
source: "[[원본 노트 또는 Archive/raw 경로]]" # 외부 기반일 때만 기입, 순수 내 생각이면 비움
stage: seed       # BRAIN 성장 단계 (seed | bloom | connected)
---
```

### 4. 본문 구조 (`_TEMPLATES_/BRAIN-Note.md` 준수)
```markdown
# [한 문장 명제]

## 요약
> 핵심 결론을 1~2문장으로 먼저 씁니다.

## 1. 개요
> **Background (배경):** 기록의 이유와 맥락

- [사용자 B 답변 반영]

## 2. 생각

### Resonate (공명 — 가장 울린 한 줄)
> [원문 인용 — 있을 때만]

- [사용자 R 답변 반영]

### Amplify (확장 — 내 생각 · 반박 · 빈틈)
- [사용자 A 답변 및 검토할 질문 반영]

## 3. 활용
*(초기 `seed` 단계에서는 비워 두고, `/brain-connect`에서 채웁니다.)*

### Integrate (연결)
- 🟢 **동조하는 생각:** [[ ]]
- 🟡 **대조되는 생각:** [[ ]]
- 🔵 **적용 가능한 곳 (Lab/Projects):** [[ ]]

### Navigate (다음 한 걸음)
- **다음에 읽을 것:** [[ ]]
- **다음에 쓸 것:** 🎯 
- **미해결 질문:** ? 
```

### 5. 완료 보고
- 저장한 경로와 태그·상태(`status: draft`, `stage: seed`)를 보고하고, 다음 선택지(`/brain-brainify` 또는 `/brain-connect`)를 안내합니다.

---

## 절대 하지 않는 것
- ❌ 사용자 답변 없이 B·R·A를 AI 마음대로 지어내 채우기
- ❌ `status: seed`처럼 5규약의 `status` 값을 임의로 변경하기 (`seed`는 반드시 `stage:`에 기록)
- ❌ `tags:`에 `brain-note`, `seed` 같은 메타 상태 태그 넣기
- ❌ `3. 활용(I/N)`을 `seed` 단계에서 미리 억지로 채우기
- ❌ `Ark/` 아래에 임의로 새 폴더 생성하기
