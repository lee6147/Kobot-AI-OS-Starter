# log — 오늘 한 작업을 2~3줄 영수증으로 남기기 (`Kobot-AI-OS-Starter` 공용)

> 📝 파이프라인 위치: **Part 7 수집·정리 4축 중 네 번째 — 내 작업 기록.**
> 강사 `Clip 7.1.4` 최종 표준대로 지저분한 1층 자동 Hook 없이 **2층 `/log` 단독 운용**을 기본으로 합니다.

## ⚙️ 경로 설정 (`Kobot-AI-OS-Starter` 표준)

| 이름 | 설정값 | 설명 |
|---|---|---|
| `DAILY_DIR` | `Ark/기록-인사이트/Daily/` | 오늘 Daily Note 위치 (`YYYY-MM-DD.md`) |
| `LOG_HEADING` | `## 오늘 한 일 (Log)` | 세션 요약 착지 섹션 |
| `PROJECTS_DIR` | `Lab/Projects/` | 상위 프로젝트 `## 📝 진행 로그` (새 세션 복원 허브) |
| `TASKS_DIR` | `Lab/Tasks/` | 관련 태스크 `## 💡 세션 메모 & 다음 태스크` |

## 에이전트 실행 절차
1. **재료 읽기 & 데일리 노트 확인:** 오늘 Daily Note(`DAILY_DIR/{오늘 YYYY-MM-DD}.md`)의 `LOG_HEADING`, 현재 대화 맥락(**무엇을 · 왜**), 실제로 생성/수정한 산출물 경로를 확인합니다.
   - 만약 `DAILY_DIR` 폴더나 오늘 Daily Note가 아직 없다면 멈추지 말고 *"오늘 날짜 Daily Note가 아직 없어 기본 뼈대를 만든 뒤 로그를 남길까요?"*라고 1줄 확인한 뒤, 폴더 생성 및 `_TEMPLATES_/Daily-Note.md`(`{{date:YYYY-MM-DD}}`, `{{date-1d:YYYY-MM-DD}}`, `{{date+1d:YYYY-MM-DD}}` 치환, `## 오늘의 계획`은 빈칸 유지)로 파일을 생성합니다.
2. **요약 제안 (확정 전 — Editor-in-Chief):**
   ```markdown
   ### HH:MM · 세션 요약
   - 무엇을 · 왜 — [한 줄. 반드시 '왜(Why)'가 들어갈 것]
   - 산출물 — [[노트A]] · [[노트B]]
   ```
   - `'왜'`가 빠진 밋밋한 요약은 통과시키지 않고 되묻습니다.
   - **분량 가드:** 한 세션 2~3줄, 하루 전체 3~5줄.
3. **확정 후 기록 (append-only):** 사용자가 승인·수정한 문장을 `LOG_HEADING` 맨 끝에 추가합니다. (기존 줄 삭제·수정 금지, 자기 자신 링크 금지)
4. **관련 태스크 & 상위 프로젝트 동기화 (조건부):** 관련 태스크 및 상위 프로젝트(`## 📝 진행 로그`)에도 1줄 남길지 확인 후 append합니다.

## ❌ 안 하는 것
- 사용자 확인 없이 바로 기록하기
- `'왜(Why)'`가 빠진 요약을 그대로 통과시키기
- 기존 로그 줄을 삭제하거나 덮어쓰기
