# 🚀 코봇 팀 LLM Wiki & AI OS 가이드 — ① 터미널 익숙 버전

> **대상:** Antigravity, Gemini CLI, Codex 등 로컬 코딩 에이전트 및 Git 사용이 익숙한 코봇 팀원  
> **핵심:** 방대한 강의 문서를 일일이 열어볼 필요 없이, 스타터 레포(`Kobot-AI-OS-Starter`)를 받아 **에이전트에게 `/kobot-onboard` 한 번만 실행시키면** 내 전공·역할에 맞춘 개인 AI OS가 자동으로 세팅됩니다.  
> **원리·깊이 안내:** 전체 개념과 폴더 설계 이유가 궁금할 땐 [[_GUIDES_/Part1~3-핵심정리]] · [[_GUIDES_/Part4~9-핵심정리]]를 보거나 에이전트에게 *"[[_BOT_PACK_/KOBOT_STARTER_KNOWLEDGE_PACK]] 기준으로 이 원리 설명해 줘"*라고 물어보세요!

## 1. 3분 초기 세팅 (`Kobot-AI-OS-Starter`)

1. 팀장 배포 GitHub 저장소(`Kobot-AI-OS-Starter`)를 로컬에 `git clone`합니다. *(본인 개인 볼트를 원격에 올릴 때는 Private 레포 권장)*
2. **Obsidian을 먼저 켜지 말고**, `Kobot-AI-OS-Starter` 폴더를 작업 경로로 AI 에이전트(Antigravity · Gemini CLI · Codex 등)를 연 뒤 첫 마디로 **"온보딩 시작"**(`/kobot-onboard`) 또는 **`/kobot-guide`**("Part 1부터 / Part 4부터 순서대로 실습하자")를 입력합니다.
   - [[AGENTS]] / [[GEMINI]]의 0번 부트스트랩 규칙이 [[0_Me/ONBOARDING_STATUS]](`completed: false`)를 감지해 자동으로 1:1 인터뷰를 시작하거나, 요청 시 `/kobot-guide` Stage 0 워밍업부터 진행합니다.
   - *(예외: 브라우저 **Obsidian Web Clipper**를 쓰고 싶을 때만 처음 1회 Obsidian에서 `"Open folder as vault"`로 열어 볼트를 등록하면 됩니다. 웹 클리퍼 없이 채팅창에 URL·텍스트를 바로 던지면 Obsidian 0회로도 완주 가능합니다.)*
3. 4단계 질문(프로필 · L2/L3 역할과 프로젝트 · 지식 영역 3~5개 · 5S 기록 진단)에 답하고 제안된 폴더·태그안을 승인하면 개인 맞춤형 볼트가 자동 생성됩니다.
4. 이후에는 `/kobot-guide`를 불러 Part 1~9 단계별로 원리 설명과 실습을 1:1로 이어갈 수 있습니다.

## 2. 왜 이 구조를 쓰나요? (핵심 원리 요약)

- **챗봇 창을 닫아도 지식이 남게 하기 위함:** 매번 새 채팅에서 배경을 다시 설명하는 대신, 내 맥락(`0_Me/`)과 규칙([[AGENTS]] / [[GEMINI]])을 로컬 파일로 영속화합니다.
- **내 생각(`Ark/`) vs AI 책장(`Archive/wiki/`) 격리:**
  - `Ark/`: 내가 직접 쓴 공부 정리([[_TEMPLATES_/BRAIN-Note]])와 일상 기록. AI가 임의로 덮어쓰지 않습니다.
  - `Archive/raw/`: 논문·데이터시트·강의 요약 등 **수정 금지 원본**.
  - `Archive/wiki/`: AI가 `raw/`와 `Ark/Blocks/`를 읽고 컴파일·교차참조해 두는 백과사전([[Archive/wiki/index]], [[Archive/log]] 동시 갱신).
- **Frontmatter 5규약 ([[0_Me/_FRONTMATTER_REGS]]):** `type`, `created`, `tags`, `status`, `source` 5개 키를 통일해 노트가 수백 개로 늘어나도 에이전트와 옵시디언이 정확히 찾습니다.

## 3. 매일 쓰는 2가지 워크플로우

### ① 공부한 개념을 내 자산으로 고정할 때 (`Ark/`)
```text
/brain-add-seed [방금 공부한 내용 또는 Welcome/ 메모]
```
- AI가 **B(배경) · R(공명) · A(확장)** 3가지 질문을 던지고, 내 답을 받아 `Ark/<내 주제 방>/`에 1장 심습니다. (말로만 안 와닿는 물리·회로 개념은 A 질문에서 비유·도식·HTML 시뮬레이션으로 만들어 달라고 요청하고, 하루 끝 회고는 [[_TEMPLATES_/Daily-Reflect]] 2문항만 가볍게 남기세요.)
- 나중에 살을 붙일 땐 `/brain-brainify`, 볼트 내 다른 노트·프로젝트와 이을 땐 `/brain-connect`, 재사용 명제 1~3개를 뽑을 땐 `/brain-distill` → 위키 반영은 `/brain-wiki-sync`를 씁니다.

### ② 데이터시트·논문·강의를 AI 책장에 넣고 빈틈 찾을 때 (`Archive/`)
```text
/ingest [Archive/raw/ 경로 또는 본문/URL]
/query [내가 이해한 개념 설명 + 빈틈·오개념 짚어달라는 질문]
```
- **백지 돌파 팁 (역질문 코칭):** 뭐부터 적을지 막막할 때는 **`/query [주제] 핵심 진단 질문 3~4개만 먼저 내서 내 이해도를 테스트해 줘`**라고 시키세요. 1줄씩(모르면 "모름") 답하면 AI가 기존 개념과 뒤섞인 오개념을 초보자 비유로 정확히 짚어줍니다.
- **주의사항:** 기존 자료 50개를 한꺼번에 `Archive/raw/`에 넣지 마세요. **이번 주 실제로 쓸 자료 1~2건씩만** 선별 복사(녹취 전문 제외, 핵심 이미지 선별)해 바로 `/ingest`까지 끝내는 것이 AI 탐색 정확도를 지키는 비결입니다.

## 4. Part 7~9 자동 수집·출력·리뷰 확장 & 2단계 전략
- **2단계 추천 운영 전략 (Obsidian 최소화 → Grok 일상 활용):**
  1. **1단계 (구축·실습):** `git clone` 후 **Obsidian을 계속 켜두지 않고도** AI 앱(Antigravity · Gemini CLI · Codex 등) 창 하나만으로 온보딩~Part 9를 완주합니다. *(단, 웹 클리퍼 URI 등록 시 1회, 그리고 노트가 15~20개 이상 쌓인 뒤 월 1회 그래프 뷰 4렌즈 육안 점검 시 Obsidian 열기 권장)*
  2. **2단계 (일상 활용):** 구축이 끝나면 매일 할 일과 위키 조회는 가시성이 좋은 **Grok 에이전트** 등으로 간편하게 굴립니다.
- **수집·실행·출력 확장 명령 (볼트 내부 완결형 · 외부 앱/Hook 불필요):**
  - **웹 클리퍼 (`_TEMPLATES_/Web-Clipper/*.json` 4종):** `https://` 트리거 & 상단 `## 저장 이유 & 내 반응 (한 줄)` 포함 검증 완료본 → `Archive/raw/` 직결.
  - **음성 1분 덤프:** 무료 OS 받아쓰기(`Win+H` 등)로 말하면 AI가 `Welcome/` 원문 무삭제 보존 + `Ark/` 브레인 노트로 2단계 변환.
  - **`/planner-align` · `/log`:** 외부 앱·1층 자동 Hook 없이 데일리 노트([[_TEMPLATES_/Daily-Note]]) ↔ `Lab/Tasks/` 정렬 및 세션 끝 2~3줄 작업 영수증('왜' 필수 + 상위 `Lab/Projects/` 진행 로그 동기화).
  - **`/create-card-news`:** 완성 노트·초안을 5장 요약 카드 + 공유 캡션(`Outputs/카드뉴스/`)으로 압축.
  - **Review & 지속 운영 (`_TEMPLATES_/` 3종):** 매일 저녁 Daily Review 2단(AI 통합 요약 + **내 해석 3줄**), 주 1회 [[_TEMPLATES_/Template_Weekly-Review]] + `/lint`, 월 1회 [[_TEMPLATES_/자가진단-3축]](최저점 1개만 30일 강화), [[_TEMPLATES_/30-90-365 체크리스트]]로 초기 30일 루틴 고정.
- **1주차 필수 (이것만 쓰세요):** `/kobot-onboard`(초기 세팅) → `/brain-add-seed`(내 생각 1장), `/ingest`(외부 자료 1건), `/query`(빈틈 찾기·역질문 코칭), `/log`(작업 끝 2줄)
- **2주차 이후 심화:** `/brain-brainify` → `/brain-connect` → `/brain-distill` → `/brain-wiki-sync` · `/planner-align` · `/create-card-news` · `/lint`
- **노션과 어떻게 병행하나요?** 개인 공부·원본 축적은 로컬 볼트에서 하고, 팀 공유·발표용 완성본(`Outputs/`)만 노션으로 내보내면 이중 기록이 없습니다.
