> **대상:** 터미널/CLI 도구가 낯설고, 웹 **Gemini · Grok · ChatGPT**와 **Obsidian / Notion** 중심으로 가볍게 시작하고 싶은 코봇 팀원  
> **핵심:** 터미널 명령어나 복잡한 강의 `.md`를 전혀 몰라도 됩니다. **`_BOT_PACK_/` 폴더 안의 딱 2개 파일만 웹 봇에 올리면**, 봇이 내 기록을 보고 **"어느 폴더에 무슨 이름으로 저장할지 + 복붙용 완성 파일"**을 통째로 만들어 줍니다.  
> **원리·깊이 안내:** 전체 개념과 폴더 설계 이유가 궁금할 땐 [[_GUIDES_/Part1~3-핵심정리]] · [[_GUIDES_/Part4~9-핵심정리]]를 보거나 봇에게 *"[[_BOT_PACK_/KOBOT_STARTER_KNOWLEDGE_PACK]] 기준으로 이 원리 설명해 줘"*라고 물어보세요!

## 1. 3분 초기 세팅 (터미널 0% 사용)

1. 팀장 배포 GitHub 저장소(`Kobot-AI-OS-Starter`) 페이지에서 오른쪽 초록색 **`Code` → `Download ZIP`**을 눌러 압축을 풉니다.
2. **Obsidian**을 실행해 `"Open folder as vault"`를 누르고 압축 푼 `Kobot-AI-OS-Starter` 폴더를 엽니다.
3. 본인이 쓰는 웹 AI에서 봇을 1개 만듭니다:
   - **Gemini 사용 시:** `Gem 만들기` → **지침** 칸에 [[_BOT_PACK_/BOT_SYSTEM_PROMPT]] 내용 전체 복사 붙여넣기 + **파일 추가**로 [[_BOT_PACK_/KOBOT_STARTER_KNOWLEDGE_PACK]] 업로드
   - **Grok 사용 시:** 새 `Project` 생성 → **Custom Instructions**에 `BOT_SYSTEM_PROMPT.md` 복붙 + **Files**에 `KOBOT_STARTER_KNOWLEDGE_PACK.md` 업로드
4. 봇 채팅창에 **"온보딩 시작"**이라고 입력합니다.
   - 봇이 질문 4개로 내 전공·역할·관심 주제를 파악한 뒤, 옵시디언에 만들 폴더 목록과 `0_Me/` 파일 완성본을 바로 뽑아 줍니다.
   - **꿀팁:** 온보딩 마지막에 봇이 뽑아 주는 **`[내 볼트 프로필 요약 — 새 채팅 시작 시 복붙용]` 5줄 박스**를 메모해 두었다가, 다음에 새 채팅창을 열 때 첫 줄에 붙여넣으면 봇이 내 폴더와 태그를 즉시 기억합니다.

## 2. 왜 이렇게 폴더를 나누나요? (딱 4줄 이해)

- **`Welcome/`:** 생각나자마자 급히 던져 두는 바구니 (분류 고민 금지)
- **`Ark/`:** 내가 직접 이해하고 쓴 공부·일상 노트 (`내 생각 방주`)
- **`Archive/wiki/`:** 강의·논문·데이터시트 같은 외부 자료를 AI 봇이 요약해 주는 `AI 백과사전` (원문은 수정 금지 `Archive/raw/`)
- **`Lab/` & `Outputs/`:** 진행 중인 과제·스터디(`Lab/`)와 팀 발표·포트폴리오 완성본(`Outputs/`)

## 3. 평소에 쓰는 방법 (채팅에 던지고 복붙하기)

### 패턴 ① 오늘 공부한 내용·메모 정리하기
봇에게 아무 메모나 던져 보세요:
> *"오늘 수업에서 PWM 제어 배웠는데, 듀티비 바꿀 때 평균 전압 변하는 게 핵심인 것 같아. 어디에 어떻게 저장할지 만들어 줘."*

그러면 봇이 자동으로 1~2개 확인 질문(`내 생각`)을 던진 뒤 아래 4가지를 한 번에 출력합니다:
1. **저장할 폴더 위치** (예: `Ark/임베디드-제어/`) + 왜 거기인지 이유
2. **추천 파일명** (예: `PWM 듀티비가 모터 평균 전압을 결정한다.md`)
3. **옵시디언에 그대로 붙여넣을 완성 `.md` 코드블록** ([[0_Me/_FRONTMATTER_REGS]] 5규약 태그·속성 자동 완성)
4. *(외부 자료 위키일 경우)* [[Archive/wiki/index]]와 [[Archive/log]] 끝에 복사해 붙일 1줄 스니펫

### 패턴 ② 내가 이해한 게 맞는지 빈틈 점검받기 (역질문 코칭 포함)
> *"내가 이해하기로는 부트스트랩 커패시터가 어쩌고... 맞는지 확인해 줘."*  
> *(또는 뭐부터 적을지 막막할 때)* ***"방금 올린 자료에서 내가 꼭 알아야 할 핵심 진단 질문 3개만 먼저 내줘. 1줄씩 답할게(모르면 모른다고 할게). 설명은 초보자 비유나 시뮬레이션으로 해줘."***

봇이 첨부 자료 근거 vs 일반 지식을 구분해서 **맞은 점 · 기존 개념과 섞인 오개념 · 초보자 비유**를 바로 짚어 줍니다.

### 패턴 ③ 하루 끝 1분 성찰 남기기 (`Daily-Reflect` 2문항)
- 할 일 관리는 `Lab/Tasks/`에 맡기고, 하루 끝에는 봇에게 **① 오늘 바로잡은 핵심 1개 + ② 한 번에 안 와닿아 다시 볼 부분 1개**만 말해 `Ark/기록-인사이트/`용 파일([[_TEMPLATES_/Daily-Reflect]])로 뽑아 붙여넣으면 부담 없이 기록이 쌓입니다.

### 패턴 ④ 노션(Notion)이랑 같이 쓰고 싶다면?
- 평소 공부와 자료 정리는 위 방식대로 Obsidian(`Ark/`, `Archive/wiki/`)에 차곡차곡 쌓고,
- **스터디 발표나 팀원에게 공유할 완성본(`Outputs/`)만 노션 페이지로 복사해 발행**하면 노션과 옵시디언에 똑같은 글을 두 번 쓰는 수고를 완전히 없앨 수 있습니다.

## 4. 주의할 점 & 2단계 확장 활용 (`Part 7 ~ Part 9` 반영)

2. **AI 요약만 저장하지 마세요:** 웹 클리핑(`_TEMPLATES_/Web-Clipper/*.json`)이든 음성 메모든 **내 반응·저장 이유 1줄**이 들어가야 3주 뒤에도 기억에 남습니다.
3. **2단계 추천 동선 (Obsidian 최소화 → Grok 일상 활용):**
   - **1단계 (초기 세팅·실습):** Obsidian을 계속 켜둘 필요 없이, 웹 **Gemini Gem / ChatGPT / Claude / Antigravity** 창 하나만으로 온보딩~Part 9 핵심 흐름(음성 1분 덤프 → 2단계 변환, `/planner-align`·`/log` 작업 영수증, 5장 카드뉴스)을 가볍게 익힙니다. *(웹 클리퍼 URI 연동 시에만 Obsidian 1회 열기 필요)*
